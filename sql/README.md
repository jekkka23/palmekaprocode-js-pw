# Первый SELECT

Файл [active-customers.sql](active-customers.sql) содержит только запрос. Редактор полигона не принимает SQL-комментарии, поэтому пояснения стоят здесь сразу после каждой строки запроса.

1. `SELECT id, name, city` - выбираем только три столбца покупателя.
2. `FROM customers` - читаем таблицу покупателей.
3. `WHERE active = 1` - оставляем активных покупателей.
4. `ORDER BY id;` - сортируем строки по id и завершаем запрос.

На исходных данных результат содержит шесть строк с id 101, 102, 104, 105, 106 и 107. Запрос можно целиком вставить в [SQL-песочницу](https://palmekaprocode.ru/practice/sql-lab).
