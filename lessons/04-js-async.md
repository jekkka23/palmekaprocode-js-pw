## Зачем это нужно в автотесте

Автотест открывает страницу, нажимает кнопку и получает данные не мгновенно. Если начать проверку раньше завершения действия, можно увидеть старое состояние и получить случайное падение. await помогает дождаться результата, прежде чем выполнять следующую строку.

В этом уроке вместо браузера будет маленькая программа на Node.js: она подождет учебный ответ и покажет, в каком порядке выполняются строки. Затем мы разберем ошибку. Когда дойдем до Playwright, тот же принцип понадобится для действий со страницей и запросов к серверу.

- Увидеть результат до и после ожидания
- Понять, что возвращает async функция
- Обработать успешный ответ и ошибку

## Сначала разберем слова

Сначала представим медленную загрузку ученика. Таймер в примере создает короткую учебную задержку, чтобы порядок стал заметен. Настоящий ответ сайта мы здесь не получаем. Функция вернет знакомый объект с именем и признаком активности.

- **Promise**: объект с будущим результатом: работа еще идет, а значение появится позже или вместо него придет ошибка.
- **async**: ставится перед function. Вызов такой функции возвращает Promise, даже если внутри return отдает обычный объект.
- **await**: ждет завершения Promise и дает следующей строке готовое значение. Его пишут внутри async функции или на верхнем уровне модуля.
- **node:timers/promises**: встроенный модуль Node.js. Его setTimeout(300) возвращает Promise, который завершится примерно через 300 миллисекунд.
- **try/catch**: блок try содержит действие, которое может завершиться ошибкой; catch получает эту ошибку и позволяет вывести понятное сообщение.
- **throw**: прерывает обычное выполнение и передает ошибку. В async функции из-за него возвращенный Promise завершится ошибкой.
- **Error**: объект ошибки с сообщением. В new Error("Не удалось получить ученика") это сообщение доступно через error.message.

## Как это работает

JavaScript напечатает "До ожидания" и вызовет loadStudent(). Поскольку функция объявлена с async, вызов даст Promise. Строка await loadStudent() дождется, пока внутри функции закончится таймер и return отдаст объект. Лишь после этого программа напечатает имя и активность ученика.

- Импортируем встроенный таймер, который возвращает Promise
- async функция ждет таймер и возвращает объект ученика
- await получает этот объект, когда работа закончилась
- Только после await читаем свойства name и isActive

## Проследите порядок выполнения

Вызов loadStudent() не отдает объект немедленно: сначала появляется Promise. await приостанавливает дальнейшие строки файла, пока Promise не завершится. Внутри loadStudent() после таймера выполнится return, и сохраненный в student результат можно читать через точку.

**Обратите внимание.** await стоит снаружи функции на верхнем уровне файла. Это работает потому, что package.json помечает файлы .js в папке как модули. В будущей спеке Playwright await будет стоять внутри async функции теста.

## Что поменять для проверки понимания

Меняйте по одному месту, сохраняйте нужный файл и снова запускайте его. Сначала предскажите вывод, затем проверьте себя. После каждой проверки верните исходный код.

## Как это пригодится в Playwright

В будущем тесте page.goto(), click() и запрос к серверу тоже дают Promise. После await можно работать с полученным результатом или проверять состояние страницы. Для UI-проверки ждите наблюдаемый результат: видимый элемент, нужный адрес страницы или конкретный ответ. Учебный setTimeout из этого урока в тест переносить не нужно.
