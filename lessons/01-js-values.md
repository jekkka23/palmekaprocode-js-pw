# 1. Переменные, типы и условия

[Открыть урок на сайте](https://palmekaprocode.ru/courses/qa-auto-javascript/lessons/js-values)

## Зачем этот урок

Представьте будущий автотест формы ученика. Перед заполнением формы ему нужны данные и простое правило: можно ли использовать эту запись. Здесь мы напишем маленькую программу, которая проверяет имя, возраст, активность и почту ученика.

Программа работает без сайта: она напечатает "Данные готовы", если все условия выполнены, или "Проверьте данные", если хотя бы одно условие не прошло. Так мы разберем основу логики, которая позже появится внутри автотеста Playwright.

- Задаем исходные данные ученика
- Сравниваем их с ожидаемыми значениями
- Получаем понятный результат проверки

## Что подготовить перед началом

Для запуска нужен Node.js: он выполняет JavaScript-файл на вашем компьютере. Playwright и доступ к тренировочному полигону пока не нужны. Установку проекта и npm подробно разберем в следующем блоке курса.

- Откройте терминал и введите node --version. Если появился номер версии, Node.js уже установлен.
- Если команда не найдена, установите Node.js с официального сайта https://nodejs.org/ и откройте терминал заново.
- Создайте папку palmekaprocode-js-pw, а внутри нее папку javascript. Откройте palmekaprocode-js-pw в редакторе, например VS Code. Дальше команды запускаем из ее корня.

## Сначала разберем слова

Читаем эти слова на примере одной записи ученика. Тип значения важен: возраст 18 - число, а "18" - строка. Условия помогают превратить отдельные проверки в один ответ: готовы данные или нет.

- **Переменная**: имя для значения в программе. Например, student хранит данные ученика, а age - его возраст.
- **const**: объявляет переменную, которой нельзя присвоить другое значение. Свойства объекта внутри const менять можно.
- **let**: объявляет переменную, значение которой можно заменить позже. Используйте, когда замена действительно нужна.
- **Тип данных**: показывает, что хранится в значении и какие действия с ним возможны: текст, число, логическое значение и другое.
- **string**: строка: текст в кавычках. "18" остается текстом, даже если внутри написаны цифры.
- **number**: число без кавычек. 18 можно сравнивать с другими числами и использовать в вычислениях.
- **boolean**: логический тип с двумя значениями: true - да, false - нет. Подходит для признака активности и результата проверки.
- **undefined**: значение переменной, которой ничего не присвоили. Например, после let mentor; значение mentor равно undefined.
- **null**: явно заданное отсутствие значения. Например, phone: null означает, что телефон пока не указан.
- **object**: объект объединяет связанные значения под именами свойств. У student есть свойства name, email и age.
- **if**: выполняет код внутри фигурных скобок, только когда условие дает true.
- **else**: выполняет другой блок кода, когда условие в if дало false.
- **===**: строго сравнивает значения вместе с их типами. 18 === "18" дает false.
- **&&**: означает "и": все условия по обе стороны должны быть true.
- **>=**: означает "больше или равно". Проверка age >= 18 дает true для 18 и 19, но false для 17.
- **length**: свойство строки с числом символов. student.name.length > 0 проверяет, что имя не пустое.
- **console.log**: выводит сообщение в терминал. В этом уроке так увидим результат работы программы.

## Как это работает

JavaScript выполнит строки сверху вниз. Сначала создаст объект student, затем вычислит несколько ответов true или false, объединит их через && и выберет ветку if или else. Пока мы проверяем только данные, без кликов по форме.

- student хранит строки, число и boolean
- hasName, isAdult и emailMatches получают true или false
- canStart дает true, только если все проверки прошли
- if и else выводят один из двух результатов

## Как запустить пример

Код хранится в обычном файле с расширением .js. Node.js прочитает файл сверху вниз и покажет сообщение от console.log в терминале.

- В папке javascript сделайте файл lesson-1.js и вставьте в него весь пример из блока выше, включая серые комментарии.
- Откройте корень palmekaprocode-js-pw в VS Code, затем выберите меню "Терминал" и пункт "Новый терминал".
- Введите node javascript/lesson-1.js и нажмите Enter.
- С исходными данными вы увидите: Данные готовы.

**Обратите внимание.** Если терминал пишет, что команда node не найдена, проверьте установку Node.js и откройте терминал заново. Если файл не найден, откройте терминал в корне palmekaprocode-js-pw и проверьте путь javascript/lesson-1.js.

## Проверьте второй результат

Чтобы понять работу условия, меняйте по одному значению и после каждой правки снова запускайте node javascript/lesson-1.js из корня проекта. При повторном запуске файл читается заново.

- Поменяйте age: 18 на age: 17. Условие isAdult станет false, в терминале появится "Проверьте данные".
- Верните age: 18 и поменяйте email ученика на другой адрес. emailMatches станет false, результат будет таким же.
- Верните исходные значения. Все проверки снова дадут true, программа напечатает "Данные готовы".
