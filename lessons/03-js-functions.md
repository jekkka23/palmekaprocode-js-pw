## Зачем это нужно в автотесте

Представьте два автотеста формы ученика. Каждому нужна своя учебная почта: student-17@example.ru и student-18@example.ru. Если собирать адрес вручную в каждом тесте, легко ошибиться в одной из строк. Функция собирает адрес по одному правилу и принимает только номер ученика.

К концу урока вы напишете такую функцию, вызовете ее с разными номерами, а затем вынесете в отдельный файл. Позже другие тесты смогут подключать этот файл и готовить свои данные. Сейчас работаем без сайта и Playwright, чтобы увидеть результат прямо в терминале.

- Передать функции разные номера учеников
- Получить из нее готовые адреса
- Подключить одну функцию из другого файла

## Что уже надо знать

Достаточно первых двух уроков. Вы уже создавали .js файл, запускали его через Node.js, сохраняли значения в const и читали вывод console.log. Во втором уроке запись (row) => row.name работала как короткая функция; здесь разберем функцию отдельно и дадим ей имя.

- Число 17 пишется без кавычек, а текст "student-" - в кавычках.
- const firstEmail сохранит результат, который вернет функция.

## Сначала разберем слова

Сначала договоримся об одном правиле для адреса: текст "student-", затем номер, затем "@example.ru". Оператор + соединит эти части в строку. Когда одна из частей - строка, число 17 тоже станет текстом внутри адреса. Одна функция применит это правило к любому переданному номеру.

- **Функция**: блок кода с именем, который можно выполнить несколько раз. Слово function начинает ее объявление.
- **Параметр**: имя для входного значения в объявлении функции. В makeStudentEmail(number) это number; конкретного числа пока нет.
- **Аргумент**: конкретное значение при вызове функции. В makeStudentEmail(17) аргумент 17 попадет в параметр number.
- **Вызов функции**: запись с круглыми скобками после имени: makeStudentEmail(17) запускает код функции.
- **return**: завершает работу функции и отдает результат в место вызова. console.log только печатает значение, но не возвращает его.
- **Модуль**: отдельный файл с кодом, который можно подключить из другого файла. В этом уроке модулем будет student-data.js.
- **export**: открывает функцию для использования в другом модуле. Без export ее нельзя импортировать по имени.
- **import**: подключает экспортированную функцию. Путь "./student-data.js" означает файл рядом с текущим.
- **package.json**: файл настройки папки проекта. Поле "type": "module" сообщает Node.js, что обычные .js файлы в этой папке используют import и export.

## Как это работает

Объявление function makeStudentEmail(number) сообщает JavaScript, что делать позже, но само по себе ничего не печатает. При вызове makeStudentEmail(17) значение 17 попадает в number. Строка return собирает адрес и отдает его в firstEmail. Второй вызов с 18 выполняет тот же код заново и возвращает другой адрес.

- Объявляем makeStudentEmail с параметром number
- Передаем 17 и 18 при двух вызовах
- return отдает готовую строку каждому вызову
- console.log печатает сохраненные результаты

## Проследите первый вызов по шагам

Имя number внутри объявления - параметр, а число 17 в вызове - аргумент. Значение параметра существует только во время работы функции. После return выполнение этой функции заканчивается, и программа переходит к следующей строке после вызова.

**Обратите внимание.** Во втором вызове параметр number получит 18. Значение первого вызова не меняется: firstEmail и secondEmail хранят два отдельных результата.

## Как запустить оба примера

Сначала запустите вариант с одним файлом, затем вариант из двух файлов .js. Во втором варианте нужен package.json из блока выше. Все четыре файла лежат в javascript/lesson-3; команды ниже выполняйте из корня palmekaprocode-js-pw.

- Сохраните первый пример как javascript/lesson-3/lesson-3.js и выполните node javascript/lesson-3/lesson-3.js.
- Создайте package.json, затем сохраните следующие блоки кода в отдельных файлах student-data.js и check-students.js рядом с ним.
- Выполните node javascript/lesson-3/check-students.js. Запускать student-data.js отдельно не нужно: функция из него выполняется при вызове в check-students.js.

**Обратите внимание.** Если import не работает, проверьте поле "type": "module" в package.json. Если Node.js не находит student-data.js, проверьте имя файла, расширение .js и путь ./student-data.js в строке import.

## Какой вывод ожидать

Обе команды напечатают одни и те же две строки. В первом случае функция находится рядом с вызовами, во втором приходит через import. Аргумент 17 дает первый адрес, а аргумент 18 - второй.

```text
Первый адрес: student-17@example.ru
Второй адрес: student-18@example.ru
```
