# 7. Общий хелпер входа

[Открыть урок на сайте](https://palmekaprocode.ru/courses/qa-auto-javascript/lessons/playwright-auth)

## Зачем это нужно в автотесте

Тренировочное поле закрыто. Без входа сайт открывает страницу /login, и тест не видит поля тренажера.

Почту и пароль не пишем в каждой спеке. Их держит один общий файл. Спека, которой нужен кабинет, вызывает функцию login в начале. Функция сама открывает вход и входит.

- Файл входа: tests/helpers/login.js
- Вызов в спеке: await login(page)
- После вызова тест открывает нужный тренажер

## Что подготовить

Продолжайте в корне palmekaprocode-js-pw. Первые спеки остаются в intro/qa-playwright. Общий хелпер лежит в tests/helpers/login.js. Конфиг запуска — playwright.config.js в корне проекта.

Почта и пароль учебного аккаунта записаны только в tests/helpers/login.js. На открытом уроке этот файл не открываем и пароль не зачитываем. Если нужно войти руками, откройте файл у себя на компьютере и возьмите значения оттуда.

- Убедитесь, что в терминале открыта папка palmekaprocode-js-pw.
- Откройте tests/helpers/login.js и прочитайте комментарий под каждой строкой.
- Откройте tests/saved-session.spec.js и найдите строку await login(page).

**Обратите внимание.** В спеке нет почты и нет пароля. Они остаются в хелпере. Личный пароль в этот файл не подставляйте.

## Сначала разберем слова

- **login**: функция входа. Спека вызывает ее и передает вкладку page.
- **page**: вкладка браузера, которую Playwright дает тесту. До вызова login в ней никто не вошел.
- **await**: подождать, пока шаг в браузере закончится.
- **goto**: открыть адрес. "/login" — страница входа. Начало адреса берется из baseURL в playwright.config.js.
- **getByLabel**: найти поле по тексту подписи рядом с ним.
- **fill**: стереть старый текст поля и записать новый.
- **exact: true**: подпись должна совпасть целиком. Так поле «Пароль» не путается с кнопкой «Показать пароль».
- **click**: нажать кнопку «Войти».
- **expect**: проверка. Тест ждет кабинет и ссылку «Тренировочное поле».

## Как это работает

Новая вкладка теста пустая. Строка await login(page) открывает /login, вводит данные из хелпера и ждет кабинет. Следующая строка спеки открывает тренажер уже после входа.

- Спека импортирует login из tests/helpers/login.js
- Спека вызывает await login(page)
- Спека открывает /practice/text-box
- Проверка ждет заголовок «Текстовые поля»

## Файл tests/helpers/login.js

Откройте tests/helpers/login.js. Это единственное место с почтой и паролем учебного аккаунта. На общем экране урока файл не показывайте. Разберите комментарии у себя.

[Открыть готовый файл](../tests/helpers/login.js)

**Обратите внимание.** Если в терминале заданы QA_EMAIL и QA_PASSWORD, хелпер возьмет их вместо учебного аккаунта. Для обычного урока эти переменные не задаем.

## Спека, которая вызывает хелпер: tests/saved-session.spec.js

Откройте tests/saved-session.spec.js. В начале теста стоит await login(page). Потом тест открывает /practice/text-box и проверяет заголовок.

[Открыть готовый файл](../tests/saved-session.spec.js)

## Как запустить

Команду выполняйте из корня palmekaprocode-js-pw.

```bash
npx playwright test tests/saved-session.spec.js --project=chromium --reporter=list
```

--project=chromium берет набор тестов из playwright.config.js. Вход делает не конфиг, а вызов login внутри спеки.

## Какой результат ожидать

В отчете одна строка: тест «хелпер входа открывает тренажер». Последняя строка — 1 passed.

```text
1 passed
```

**Обратите внимание.** Раньше перед тестом шел отдельный setup, и в итоге было 2 passed. Теперь вход внутри спеки, поэтому успешный запуск этого файла — 1 passed.

## Что поменять для проверки понимания

Меняйте одну строку и верните ее обратно.

- В tests/saved-session.spec.js замените путь /practice/text-box на /practice/check-box. Вход пройдет, проверка заголовка упадет: на странице будет «Чекбоксы». Итог: 1 failed.
- Верните путь. Замените только ожидаемый заголовок на «Чекбоксы». Снова 1 failed: открыты текстовые поля.
- Верните заголовок «Текстовые поля». Повторный запуск снова дает 1 passed.

## Если запуск не прошел

- Если тест остался на /login, откройте tests/helpers/login.js и проверьте, что функция login вызывается из спеки.
- Если открылся кабинет, а заголовка тренажера нет, проверьте путь в page.goto.
- Команду запускайте из папки palmekaprocode-js-pw с --project=chromium.
