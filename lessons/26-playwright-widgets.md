# 26. Виджеты: аккордеон

[Открыть урок на сайте](https://palmekaprocode.ru/courses/qa-auto-javascript/lessons/playwright-widgets)

## Зачем проверять состояние виджета

У виджета есть начальное состояние и переход после действия. Если тест проверяет только клик, он не замечает, открылся ли нужный раздел и появился ли его текст.

В разделе "Виджеты" начнем с аккордеона. Первый пункт уже открыт, а пункт "Когда нужна автоматизация?" закрыт. Тест раскроет этот пункт, проверит его содержимое и закроет снова.

- Проверить закрытое начальное состояние
- Раскрыть раздел и увидеть его текст
- Повторным кликом закрыть раздел

## Что подготовить

Продолжайте в palmekaprocode-js-pw с проектом chromium. Спека вызывает login из tests/helpers/login.js. Откройте https://palmekaprocode.ru/practice/accordion и найдите пункт про автоматизацию.

Создайте tests/accordion/pages и tests/accordion/helpers. Новый тест запускается сам по себе и не зависит от урока про модальные окна.

- Убедитесь, что прошлый тест окон дает 1 passed.
- Проверьте руками, что пункт про автоматизацию открывается и закрывается повторным нажатием.
- Создайте три файла .js по путям ниже.

## Сначала разберем слова

У аккордеона есть кнопка #accordion-automation и панель #accordion-panel-automation. Проверяем обе части: атрибут кнопки говорит о состоянии, текст панели подтверждает, что открылось нужное содержимое.

- **Виджет**: элемент страницы с состоянием, которое меняется после действия. Аккордеон хранит открытый пункт.
- **aria-expanded**: атрибут кнопки: false означает закрытый раздел, true - открытый.
- **toHaveAttribute**: ассерт, который ждет указанное значение атрибута.
- **toBeHidden**: ассерт, который ждет скрытия или удаления панели из страницы.

## Как это работает

Тест делает два клика по одной кнопке. Между ними проверяет открытое состояние, после второго клика - закрытое. Страница хранит локаторы и действие, хелпер - три проверяемых шага, спека - один самостоятельный test.

- Открыть /practice/accordion
- Проверить aria-expanded=false
- Нажать кнопку и проверить aria-expanded=true и текст панели
- Нажать снова и проверить закрытие

## Как запустить и что увидеть

Сохраните три файла. В корне palmekaprocode-js-pw выполните npx playwright test tests/accordion/accordion.spec.js --project=chromium --reporter=list.

В начале спека вызывает login из файла tests/helpers/login.js. Последняя строка успешного запуска - 1 passed. Шаг 2 проверит открытое состояние, шаг 3 - закрытое.

```text
1 passed
```

**Обратите внимание.** Если панель не появилась, не добавляйте фиксированную паузу. Проверьте кнопку и текст панели: ассерты уже ждут нужное состояние.

## Команды для копирования

Выполняйте команды из корня palmekaprocode-js-pw. Копируйте строку целиком, без текста пояснения.

**Запустить тест этого урока**

```bash
npx playwright test tests/accordion/accordion.spec.js --project=chromium --reporter=list
```

## Что поменять для проверки понимания

Меняйте одну строку и сначала предсказывайте шаг падения.

- В хелпере замените начальное ожидание aria-expanded=false на true. Основной тест упадет на шаге 1; итог 1 passed и 1 failed.
- Верните false. Замените ожидаемую фразу панели на "Другой текст". Основной тест упадет на шаге 2; итог 1 passed и 1 failed.
- Верните исходную фразу. Повторный запуск должен дать 1 passed.
