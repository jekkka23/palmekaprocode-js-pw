# 10. XPath: связи и строка таблицы

[Открыть урок на сайте](https://palmekaprocode.ru/courses/qa-auto-javascript/lessons/xpath-relations)

## Зачем искать по связям элементов

Не у каждого элемента есть удобный id. В дереве чекбоксов нужный input можно найти по тексту его label, а в таблице строку - по почте в одной из ячеек. XPath позволяет описать эти связи без длинного пути от корня страницы.

Разберем два конкретных случая: родительский чекбокс "Рабочий стол" и строку сотрудника с почтой irina@example.ru. Для каждого выражения сначала проверим одно совпадение, затем поведение страницы.

- Найти input внутри label с нужной подписью
- Найти строку таблицы по содержимому td
- Проверить оба XPath в отдельных тестах

## Что подготовить

Продолжайте в palmekaprocode-js-pw после первого XPath-урока. Вызов login и tests/xpath/xpath-basics.spec.js уже работают.

Откройте в браузере https://palmekaprocode.ru/practice/check-box и https://palmekaprocode.ru/practice/web-tables. В DevTools посмотрите label вокруг чекбокса и td с почтой Ирины в строке таблицы.

- Проверьте, что xpath-basics.spec.js отдельно дает 1 passed.
- Создайте tests/xpath/xpath-relations.spec.js.
- До запуска теста проверьте оба XPath в поиске панели Elements.

## Сначала разберем слова

Для чекбокса читаем DOM как фразу: внутри #check-box-tree нужен label с текстом "Рабочий стол", а внутри него input типа checkbox. В XPath это //div[@id='check-box-tree']//label[normalize-space(.)='Рабочий стол']/input[@type='checkbox'].

- **Родитель и потомок**: элементы, вложенные друг в друга. Здесь input находится внутри label.
- **normalize-space(.)**: убирает лишние пробелы у текста элемента и помогает сравнить видимую подпись целиком.
- **td**: ячейка таблицы; условие tr[td[...]] выбирает строку по содержимому ячейки.
- **Контекст**: часть DOM, в которой выполняется поиск. id дерева и таблицы ограничивают XPath нужным тренажером.

## Как это работает

Для таблицы читаем так: внутри таблицы records-table нужна строка tr, у которой есть ячейка td с почтой irina@example.ru. XPath //table[@id='records-table']//tr[td[normalize-space(.)='irina@example.ru']] найдет всю строку, и ее можно проверить целиком.

- Осмотреть вложенность input в label
- Проверить XPath чекбокса в Elements
- Осмотреть tr и td исходной таблицы
- Проверить XPath строки и запустить оба теста

## Как проверить оба выражения в DevTools

На странице чекбоксов откройте Elements и нажмите Command+F или Ctrl+F. Вставьте //div[@id='check-box-tree']//label[normalize-space(.)='Рабочий стол']/input[@type='checkbox']. Должно быть одно совпадение. Нажмите найденный label в дереве и убедитесь, что input находится прямо внутри него.

На странице веб-таблицы найдите ячейку irina@example.ru, затем ее родительскую строку tr. Вставьте //table[@id='records-table']//tr[td[normalize-space(.)='irina@example.ru']]. Должна найтись ровно одна строка, а не одна ячейка.

**Обратите внимание.** Для проверки можно открыть Console и вызвать $x("//table[@id='records-table']//tr[td[normalize-space(.)='irina@example.ru']]"). Массив должен содержать один элемент. Поиск через Elements удобнее новичку: он сразу подсветит совпадение в дереве.

## Файл tests/xpath/xpath-relations.spec.js

В файле два независимых теста. Каждый открывает нужный тренажер со своей вкладкой и проверяет свой XPath.

[Открыть готовый файл](../tests/xpath/xpath-relations.spec.js)

**Обратите внимание.** XPath в каждом тесте начинается с конкретного блока страницы. Это делает поиск понятным и уменьшает вероятность совпадения с другим тренажером.

## Как запустить и какой вывод ожидать

Сохраните файл в tests/xpath/xpath-relations.spec.js. В корне palmekaprocode-js-pw выполните npx playwright test tests/xpath/xpath-relations.spec.js --project=chromium --reporter=list.

В файле два теста. Каждый в начале вызывает login из tests/helpers/login.js. В конце успешного запуска будет 2 passed. Первый проверит дочерние галочки, второй - строку Ирины.

```text
2 passed
```

## Что поменять для проверки понимания

Меняйте одно выражение за раз и возвращайте его после проверки.

- В XPath desktop замените "Рабочий стол" на "Заметки". Первый тест упадет на проверке Команд, второй пройдет; итог 1 passed и 1 failed.
- Верните подпись. В XPath строки замените irina@example.ru на nobody@example.ru. Табличный тест упадет на toHaveCount(1), а тест чекбоксов пройдет; итог 1 passed и 1 failed.
- Верните почту. Повторный запуск снова даст 2 passed.
