# 25. Окна и уведомления: модальное окно

[Открыть урок на сайте](https://palmekaprocode.ru/courses/qa-auto-javascript/lessons/playwright-windows)

## Зачем проверять окна

После отправки формы приложение часто открывает окно с подтверждением. Тест должен увидеть именно нужное окно, проверить его текст, закрыть и убедиться, что оно исчезло.

После новой вкладки, browser alert и фреймов проверим маленькое модальное окно. Это отдельный самостоятельный тест в знакомой структуре из трех файлов. Затем тот же прием можно применить к большому окну.

- Открыть модальное окно
- Проверить его заголовок и текст
- Закрыть окно и проверить исчезновение

## Что подготовить

Продолжайте в palmekaprocode-js-pw с рабочей сессией из setup. Откройте https://palmekaprocode.ru/practice/modal-dialogs и нажмите "Маленькое окно" вручную.

Новый тест лежит в tests/modal-dialogs. Создайте внутри папки pages и helpers. Конфиг и авторизацию не копируйте.

- Проверьте, что tests/nested-frames/nested-frames.spec.js из прошлого урока дает 2 passed.
- Найдите кнопку "Маленькое окно" и текст открытого окна.
- Создайте tests/modal-dialogs/pages и tests/modal-dialogs/helpers.

## Сначала разберем слова

На странице есть кнопки для маленького и большого окна. Тест выбирает маленькое, проверяет его текст и закрывает. Проверка кнопки без состояния окна не показала бы, открылось ли оно вообще.

- **Модальное окно**: блок поверх страницы, который требует внимания до возврата к основному экрану.
- **dialog**: роль модального окна. В XPath условие [@role='dialog'] отличает его от подложки.
- **Область поиска**: часть страницы, внутри которой ищем элемент. Кнопку закрытия ищем внутри нужного dialog.
- **toBeHidden**: ассерт, который ждет исчезновения элемента после действия.

## Как это работает

Страница хранит локаторы и действия. Хелпер проверяет три состояния: исходный экран, открытый диалог и закрытый диалог. Спека запускает этот флоу с новой вкладкой и сохраненной сессией.

- Открыть /practice/modal-dialogs
- Нажать "Маленькое окно"
- Проверить заголовок и содержимое dialog
- Закрыть диалог и дождаться исчезновения

## Как запустить и что увидеть

Сохраните три файла. В корне palmekaprocode-js-pw выполните npx playwright test tests/modal-dialogs/modal-dialogs.spec.js --project=chromium --reporter=list.

Сначала пройдет setup, затем основной тест. Последняя строка успешного запуска содержит 2 passed. Шаг 2 проверит текст маленького окна, а шаг 3 подтвердит его исчезновение.

```text
2 passed
```

**Обратите внимание.** Если на шаге 2 окно не появилось, проверьте кнопку открытия. Если шаг 3 не проходит, ищите кнопку закрытия внутри smallDialog.

## Команды для копирования

Выполняйте команды из корня palmekaprocode-js-pw. Копируйте строку целиком, без текста пояснения.

**Запустить тест этого урока**

```bash
npx playwright test tests/modal-dialogs/modal-dialogs.spec.js --project=chromium --reporter=list
```

## Что поменять для проверки понимания

Меняйте одну строку, предсказывайте результат и повторяйте ту же команду.

- В хелпере замените ожидаемый текст на "Другой текст". Setup пройдет, основной тест упадет на шаге 2. Итог: 1 passed и 1 failed.
- Верните текст. В хелпере замените toBeHidden() после закрытия на toBeVisible(). Окно уже исчезло, поэтому основной тест упадет на шаге 3. Итог: 1 passed и 1 failed.
- Верните toBeHidden(). Повторный запуск должен закончиться 2 passed.
